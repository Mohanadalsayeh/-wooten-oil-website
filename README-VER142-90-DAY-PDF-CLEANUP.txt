Version 142

90-Day Manual Combined PDF Cleanup
- Added a 90-Day PDF Cleanup button beside Statement Run Report controls.
- Lists only combined Test/Run statement PDFs that are at least 90 days old.
- Shows file name, stored/upload date and time, and actual R2 object size.
- Includes per-file checkboxes and Select All.
- Delete Selected requires an explicit confirmation before permanent deletion.
- Deletion removes the R2 object and clears its Statement Run Report reference so deleted files no longer appear as usable report links.
- Cleanup is manual only; no PDF is automatically deleted at 90 days.
