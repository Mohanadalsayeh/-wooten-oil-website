WOOTEN OIL - CLOUDFLARE DIRECT FUEL REQUEST SETUP

Upload this folder to the ROOT of the GitHub repository used by your Cloudflare Pages project.
The important structure is:

index.html
functions/
  api/
    fuel-request.js
schema.sql

1. RESEND EMAIL SERVICE
- Create a Resend account.
- Add and verify wootenoil.com (or a sending subdomain such as mail.wootenoil.com).
- Create a Resend API key.

2. CLOUDFLARE ENVIRONMENT VARIABLES / SECRETS
In your Cloudflare Pages project, add:
- RESEND_API_KEY = your Resend API key (use a secret)
- FUEL_TO_EMAIL = Support@wootenoil.com
- FUEL_FROM_EMAIL = Wooten Oil Website <orders@wootenoil.com>

The FROM address must use a domain that is verified in Resend.

3. REQUIRED: PORTAL D1 DATABASE
Use the SAME D1 database used by the admin and customer portal.
Bind it to the service handling /api/fuel-request with the binding name exactly:
DB

Do not create a separate fuel-only database. The current Worker configuration
uses wooten-oil-requests. The fuel handler creates its table and adds missing
fuel-request columns automatically, preserving existing records.
Requests cannot report success unless they have been saved to this database.

4. REDEPLOY
After adding the Function and settings, redeploy the Pages project.
Test from https://wootenoil.com and submit one fuel request.

Expected behavior:
- Customer taps Submit Fuel Request.
- Website asks for confirmation.
- Request is POSTed to /api/fuel-request.
- Backend validates and saves the request before attempting either email.
- Backend independently attempts the office email and customer confirmation.
- The customer confirmation uses the configured sender, with support@wootenoil.com
  as its fallback. The sender domain must be verified in Resend.
- A saved request remains available even if email is unavailable. The form
  shows a warning instead of claiming the email was sent.
- Admin: Customer Requests > Fuel Delivery Requests > Load Requests.
- The same request number is shown to the customer and included in the email.
- FormSubmit and mailto are not used.
