WOOTEN OIL PORTAL — VERSION 70

Account Applications now include permanent deletion.

- Delete Application appears inside every expanded application.
- Only the Main Admin can delete.
- Regular admin users receive: "Only the Main Admin can permanently delete account applications."
- Main Admin receives a detailed confirmation warning before deletion.
- Secure server enforcement checks Main Admin ownership even if someone bypasses the page controls.
- Uploaded Tax ID and identity documents are deleted from private R2 storage first.
- The database application record, review status, and private admin notes are then deleted.
- If private file storage deletion fails, the application database record is kept for safety.
- Successful deletion is recorded in Recent Admin Activity with the application number and number of files deleted.
