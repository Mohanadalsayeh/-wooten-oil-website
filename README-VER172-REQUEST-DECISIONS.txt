Wooten Oil Portal Ver172

Request decision and customer notification workflow:
- Added customer Profile Change Request submission inside Account Summary.
- Profile changes remain requests only; MAS 90 stays the source of truth.
- Profile requests email support@wootenoil.com when submitted.
- Added Admin > Applications > Customer Requests for Profile Change and Fuel Delivery requests.
- Admin/Main Admin can set Pending, Accepted, or Denied.
- Admin can choose Portal, Email, SMS, or any available combination when saving a decision.
- Customer receives a portal notification when Portal is selected and an account is available.
- Fuel request decisions use the same Pending/Accepted/Denied workflow.
- Account Applications now use Pending/Accepted/Denied and include Portal/Email/SMS notification choices.
- Portal delivery for an open account application is available only when a matching existing portal account can be found; email/SMS remain available directly from the application contact information.
- Admin users with Account Applications permission can use Customer Requests.
