Wooten Oil Portal Ver170

- Password rule is now at least 8 characters with at least one letter.
- Added the password-rule notice to activation and password reset forms.
- Forgot Password now discovers available recovery methods before sending a code.
- When both are available, customers can choose Email or Text Message.
- When only one is available, only that method is shown.
- Both methods send a 6-digit code that expires after 15 minutes.
- SMS recovery supports the configured Twilio Messaging Service SID or Twilio sender number.
- When neither email nor a complete U.S. phone/SMS setup is available, the customer is directed to contact Wooten Oil.
