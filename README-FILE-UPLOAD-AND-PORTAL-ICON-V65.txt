WOOTEN OIL PORTAL — VERSION 65

1. File upload buttons
   - Applies the selected solid navy Option 1 style to portal file inputs.
   - Includes hover and keyboard-focus states.
   - Does not change accepted file types or upload behavior.

2. Live Customer Data contact icons
   - The Portal icon is always displayed.
   - Green means the customer's online portal account is activated.
   - Gray means the customer's online portal account is not activated.
   - SMS and Email icons remain visible only when those contact methods exist.
   - All contact icons remain display-only and are not clickable.
