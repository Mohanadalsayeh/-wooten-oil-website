Wooten Oil Portal Ver154

Twilio Phone Tools added:
- Default U.S. area code setting for 7-digit customer phone numbers.
- Bulk action to apply the saved area code to 7-digit customer phone numbers.
- Twilio Lookup batch validation with progress.
- Results show Valid / Invalid / Lookup Error, line type, carrier, and checked time.
- Line types include mobile, landline, fixed VoIP, non-fixed VoIP, toll-free, and other Twilio-supported types.
- Fax is not represented by Twilio Lookup as a reliable separate line type, so the admin page displays that limitation.
- Twilio Line Type Intelligence is a paid lookup and requires explicit confirmation before a customer scan.
