WOOTEN OIL PORTAL — SHARED-EMAIL ACCOUNT SWITCHER (V63)

Customer login
- Customer-number login continues to open that specific account.
- Email login checks all active customer accounts using the saved email address.
- A valid password from one activated account authorizes the active accounts sharing that email.

Account switcher
- When more than one active account shares the authenticated email, the portal displays an account chooser.
- The chooser shows the account name, customer number, current balance, and current selection.
- Customers can switch accounts without signing out or entering the password again.
- The server verifies the shared email relationship before changing the session account.
- Accounts with a different email or an inactive status cannot be opened through the switcher.
- If only one account is available, the switcher stays hidden.

Coverage
- Added to the main customer portal and the portal displayed from the Request Fuel page.
- Admin Live Customer portal-availability status recognizes access through an activated same-email account.

This package includes the V61 contact-availability icons and V62 Personal Account Tax ID update.
